\section{Fast Multipole Method}\label{sec:fmm}

The \ac{FMM} was introduced in 1987 by Greengard and Rokhlin \cite{greengardfastalgorithmparticle1987} to accelerate large-scale particle simulations involving long-range pairwise potential interactions. Later, it was extended to other problems, including the \ac{BEM} for Acoustic Scattering \cite{rokhlinrapidsolutionintegral1990}. The \ac{FMM} handles short-range interactions with direct computation, and uses analytical multipole expansions to compute potentials for long-range interactions. By providing a method for the rapid computation of the matrix-vector product between the system matrix any and arbitrary vector, the \ac{FMM} enables the use of iterative solvers for solving the linear systems arising from the \ac{BEM} discretization, reducing the computational complexity from $\mathcal{O}(N^2)$ to $\mathcal{O}(N^{\frac{3}{2}})$ or even $\mathcal{O}(N \log N)$ for a multilevel implementation \cite{coifmanfastmultipolemethod1993}.

\subsection{The \ac{FMM} algorithm} \label{subsec:fmm_algorithm}

The \ac{FMM} follows these basic steps:

\begin{enumerate}[label=\textbf{Step \arabic*.}, leftmargin=*]
    \item \textbf{Discretization:} Any problem begins with discretizing the boundary, as is done for conventional \ac{BEM}. We use constant elements.
    \item \textbf{Initializing the Octree:} For a 3D problem, we consider a cube that contains the entire geometry. This cube is repeatedly subdivided into 8 smaller cubes, called its child nodes, creating an Octree structure. The subdivision continues until the number of elements in a cube falls below a defined threshold.
    \item \textbf{Upward Pass:} Beginning from the bottom of the tree, at the deepest level called the leaf nodes, we compute the moments of each node, tracing the tree structure upwards till we are two levels below the root node. Using the \ac{M2M} translation operator, the moments of the child nodes are translated and aggregated to the parent node.
    \item \textbf{Horizontal Pass:} For nodes at level 2 and deeper, the field data is exchanged across well-separated clusters. The algorithm iterates through each node's interaction list (cousin nodes that satisfy the far-field admissibility condition). The contribution from these distant nodes is computed by converting their outgoing multipole expansions into incoming local incident fields using the M2L translation operator.
    \item \textbf{Downward Pass:} Starting from level 2, the aggregated macroscopic background field is cascaded downward. The L2L translation operator shifts the parent node's local expansion coefficients to the geometric centers of its children, where they are added to the child's independently generated local coefficients.
    \item \textbf{Evaluating of the Integrals:} The contributions of all the collocation points in the current node and the nodes directly adjacent to it are computed using direct \ac{BEM}. The contributions of all nodes in the interaction list and the far-off nodes are computed using the local expansion coefficients of the current node and shifting the expansion point to the collocation point using the \ac{L2P} translation operator.
    \item \textbf{Iterative Solver:} We update the unknown vector, in this case the \texttt{phi} vector in the system of equations $\mathbf{A} \boldsymbol{\phi} = \mathbf{b}$, using an iterative solver, such as \ac{GMRES}, and repeat from step 3 until convergence is achieved.
\end{enumerate}
